# ISEFS public website

## Build
- Create a refined, responsive public website using the supplied ENDOFACE/ISEFS identity, navy–teal palette, editorial typography, restrained motion and accessible keyboard states.
- Add shared desktop/mobile navigation and footer, using the supplied logo intact and a padded square favicon derived from it.
- Build dedicated pages for Home, About, Education & Science, Membership, Leadership, Contact, Privacy and Legal information, each with distinct metadata.
- Write finished British-English copy with careful status language: ISEFS is being established; developing programmes remain clearly labelled; the October 2026 Barcelona course is referenced without implying ownership.

## Interest and enquiry process
- Add a private Lovable Cloud table for interest registrations and enquiries, with no public read access.
- Add server-side and browser validation, a honeypot and minimum-completion-time check, duplicate prevention, and accessible loading/success/error feedback.
- Keep final submission disabled until an approved privacy notice and organisation contact details are supplied, as requested; the complete storage flow will be ready to activate once those details are confirmed.

## Content structure
- Keep events, leadership, education areas and contact-status content in small data modules so future updates are straightforward.
- Present founders typographically without fabricated portraits or credentials.
- Prepare Privacy and Legal pages as clearly marked owner-review drafts, excluded from main navigation but linked where needed.

## Verification
- Check all routes, navigation, CTAs, metadata and form states.
- Test desktop and mobile layouts for overflow, logo integrity, legibility and focus behaviour.
- Provide a separate owner handover listing confirmed work and publication blockers.
